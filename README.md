# EDA успеваемости студентов: Анализ факторов, влияющих на оценку по математике 🎓

*Учебный проект в рамках программы профессиональной переподготовки «Аналитик данных» (НИУ ВШЭ, ЦНО, г. Москва), 2025–2026.*

## 📌 О проекте

Данный проект выполнен в рамках домашнего задания №1 по курсу «Машинное обучение» программы переподготовки НИУ ВШЭ (ЦНО, г. Москва). Задача — провести разведочный анализ данных (EDA) объединённого датасета студентов, собранного из 10 групп, и выявить закономерности, влияющие на итоговую оценку по математике.

## 📌 Цель проекта

Собрать всю информацию о студентах из 10 групп в единую таблицу, провести разведочный анализ, визуализировать зависимости и определить, какие характеристики студента (пол, раса/этничность, образование родителей, тип питания, прохождение подготовительного курса, группа) вносят наибольший вклад в оценку по математике. Подготовить датасет к дальнейшему решению задач регрессии и классификации.

## 📁 Данные

- **Источник:** учебный датасет, НИУ ВШЭ (`students.zip` → папка `Data`)
- **Размер:** 1000 строк, 10 столбцов (после объединения 20 CSV-файлов)
- **Структура исходных файлов:**
  - `Students_info_0.csv` … `Students_info_9.csv` — информация о студентах по группам
  - `Students_marks_0.csv` … `Students_marks_9.csv` — оценки студентов по группам
- **Основные поля:**
  - `gender` — пол студента
  - `race/ethnicity` — расовая/этническая группа (A–E)
  - `parental level of education` → переименовано в `education` — уровень образования родителей
  - `lunch` — тип обеда (standard / free-reduced)
  - `test preparation course` → переименовано в `test preparation` — прохождение подготовительного курса
  - `group` — учебная группа (group1–group10)
  - `math score` — оценка по математике — **целевая переменная (регрессия)**
  - `reading score` — оценка по чтению
  - `writing score` — оценка по письму

- **Производные признаки:**
  - `Math_PassStatus` — сдал (`P`) / не сдал (`F`) экзамен по математике (порог `passmark = 50`)
  - `math_mark`, `reading_mark`, `writing_mark` — категориальные оценки: *неудовлетворительно / удовлетворительно / хорошо / отлично* — **целевая переменная (классификация: `math_mark`)**

## 🎯 Основные выводы (для бизнеса / анализа)

1. **Высокая корреляция между предметами:**
   Оценки по математике, чтению и письму имеют сильную положительную связь (корреляция ≈ 0.80–0.95), особенно между чтением и письмом. Чем выше балл по одному предмету, тем выше по остальным.

2. **Все категориальные признаки влияют на успеваемость (кроме группы):**
   - **Пол:** по математике мальчики успешнее, по чтению и письму — девочки. У девочек присутствуют экстремально низкие значения (0 баллов), у мальчиков минимум — 27.
   - **Тип питания:** студенты со стандартным питанием показывают более высокий средний балл (70.03 против 58.92 по математике).
   - **Образование родителей:** прямая положительная связь — чем выше образование родителей, тем выше балл студента.
   - **Раса/этничность:** группа E — самые высокие результаты, группа A — самые низкие.
   - **Подготовительный курс:** сдавшие курс успешнее (средний балл по математике 69.70 против 64.08), у них нет экстремально низких результатов (минимум 23 балла против 0 у не сдававших).

3. **Распределение оценок по математике:**
   Распределение с небольшим правым скосом и левым хвостом. 50% данных лежит в диапазоне 57–77 баллов. Среднее и медиана ≈ 66. Выбросов мало — всего 0.8% (8 значений из 1000), они ниже границы 27 баллов по правилу 1.5×IQR.

4. **85% студентов сдали экзамен по математике:**
   865 из 1000 студентов имеют балл выше проходного порога (passmark = 50).

5. **90% студентов, прошедших подготовительный курс, сдали математику:**
   Это подтверждает значимость подготовительного курса как фактора успеха.

6. **Данные чистые и пригодны для дальнейшей работы:**
   Нет пропусков, нет дубликатов. Выбросы не являются ошибками — это реальные низкие результаты, ценные для прогнозирования.

## 📊 Что сделано в проекте

1. **Загрузка данных:** распаковка архива `students.zip` через `zipfile`
2. **Задание 1 — Сборка данных:** объединение 20 CSV-файлов в единую таблицу через `pd.concat` + `pd.merge`, проверка формы и типов
3. **Задание 2 — Удаление служебного столбца `index`**
4. **Задание 3 — Базовые статистики:** `shape`, `describe` (числовые/категориальные), проверка пропусков и дубликатов
5. **Задание 4 — Интерпретация статистик:** анализ данных, гипотезы о выбросах и необходимости дополнительного анализа
6. **Задание 5 — Распределения:** гистограммы числовых признаков (50 бинов)
7. **Задание 6 — Корреляции:** матрица корреляций + комментарий
8. **Задание 7 — Средние баллы:** средние по предметам, барчарты по категориям (пол, раса, образование, тип питания, подготовительный курс)
9. **Задание 8 — Влияние подготовительного курса:** сравнение средних баллов сдавших/не сдавших курс
10. **Задание 9 — Переименование столбцов** через `rename`
11. **Задание 10 — Доли сдавших:** общая доля сдавших экзамен по математике, доля среди прошедших курс, доля женщин без курса, не сдавших экзамен
12. **Задание 11 — `groupby` + `%%time`:** агрегации с замером времени выполнения
13. **Задание 12 — Циклы + `%%time`:** те же задачи через циклы и списковые включения, сравнение производительности
14. **Задание 13 — `Math_PassStatus`:** создание столбца P/F через `apply` + подсчёт сдавших/не сдавших
15. **Задание 14 — Регрессия vs классификация:** создание категориальных оценок `math_mark`, `reading_mark`, `writing_mark` через функцию `mark_degrees`
16. **Задание 15 — Дополнительный EDA:**
    - Боксплоты оценок по математике в разрезе категориальных признаков (пол, раса, образование, тип питания, подготовительный курс, группа)
    - Проверка выбросов через правило 1.5×IQR (общее и по подгруппам)
    - Статистики `describe` в разрезе по группам
    - Heatmap корреляций
    - Pairplot для трёх числовых признаков
    - Анализ распределения `math_mark` по всем категориальным признакам
17. **Задание 16 — Итоговые выводы:** полные выводы по зависимостям, распределениям, выбросам и пригодности датасета

## 🧠 Гипотезы, проверенные в проекте

- **Подготовительный курс повышает успеваемость:** подтверждено — сдавшие курс имеют более высокие средние баллы и меньше экстремально низких результатов.
- **Пол влияет на успеваемость:** подтверждено — мальчики лучше по математике, девочки — по чтению и письму.
- **Образование родителей влияет на успеваемость:** подтверждено — прямая положительная связь.
- **Тип питания связан с успеваемостью:** подтверждено — стандартное питание коррелирует с более высокими баллами.
- **Раса/этничность влияет на успеваемость:** подтверждено — группа E стабильно показывает лучшие результаты, группа A — худшие.
- **Учебная группа влияет на успеваемость:** не подтверждено — распределение баллов по группам примерно одинаковое, значимых различий нет.
- **Числовые признаки мультиколлинеарны:** проверено через `np.linalg.matrix_rank` (ранг = 3) и определитель матрицы корреляций (≈ 0.029). Для построения регрессии рекомендуется исключить `reading score` и `writing score`, чтобы избежать мультиколлинеарности.
